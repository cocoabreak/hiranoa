# 要求定義: 名前付きワークスペースレイアウト

対象: [Issue #28](https://github.com/cocoabreak/hiranoa/issues/28)

ステータス: 初版の実装・検証完了。

## 受け入れ条件

- [x] 現在の構成を名前付きで保存し、一覧から適用・名前変更・削除できる。
- [x] 左右のタブ、ピン留め、表示モード、モード別位置、操作対象、分割比率、検索条件、Explorerのルート・展開状態を復元する。
- [x] サイドバー・目次の表示と幅、目次比率、ズームを復元する。テーマ・レンダラー・プライバシー設定は変更しない。
- [x] 適用前に現在のタブ構成を置き換えることを確認する。ピン留めも置換対象とする。
- [x] 読めない文書はスキップし、成功・スキップ件数を通知する。
- [x] NativeSourceとZipSource、およびSource横断の構成を扱う。保存情報をアクセス権として扱わず既存の認可・サイズ確認を通す。
- [x] 自動保存セッションと名前付き保存を分離する。保存済みレイアウトは閲覧操作で自動更新しない。
- [x] 最大20件、各100タブ・2ペイン、名前80文字、保存全体1MiBの上限を設ける。不明な形式は上書きせずエラーにする。
- [x] コマンドパレットから管理画面を開ける。日本語・英語、キーボード、Escape、フォーカス復帰に対応する。
- [x] 適用中の二重実行と操作競合、自動保存による途中状態の永続化を防ぐ。

## 初版の対象外

Source別分類、レイアウトごとの専用ショートカット、インポート・エクスポート、保存済みレイアウトの更新、クラウド同期。

## 決定事項

- 適用は現在の構成との合流ではなく置換とする。
- レイアウト適用時の信頼拒否・欠落は部分復元とし、すべて読めない場合も空の構成となることを確認文で明示する。
- 管理画面を閉じる操作は処理中無効とし、結果を確認してから閉じられる。
