# 要求定義: Git履歴とMarkdownのビジュアル差分

対象: Issue #26。ステータス: 実装・検証完了。左右比較の方針は承認済み。

## 受け入れ条件

- [x] NativeSourceの現在文書から履歴比較を開き、終了時に既存タブ・分割・位置へ戻れる。
- [x] Git履歴の日時・作者・概要・短縮IDを表示し、指定コミットと作業中ファイル、指定コミット同士を比較する。
- [x] 旧版・新版をそれぞれレンダリングし、段落単位の追加・削除・変更と、本文の変更語句を示す。
- [x] ソース差分へ切り替えられ、表示上同じ記法変更も確認できる。frontmatterも差分対象とする。
- [x] 前後の変更へ移動し、対応ブロック基準で同期スクロールをON/OFFできる。
- [x] 選択中の変更を中央の帯で結び、追加・削除に伴う左右の位置差を示せる。帯は装飾で操作を妨げず、非表示にでき、狭幅では隠す。
- [x] 画像は各コミットのblobから解決する。現在の画像への暗黙フォールバックをしない。図・画像・数式の内部差分は対象外。
- [x] 変更のない場合、未追跡、履歴なし、Git対象外、欠落blob、上限超過、未対応Git形式を明示する。
- [x] Gitは読み取り専用。hooks、pager、外部diff、任意コマンド、ネットワークを実行しない。
- [x] Rust側の認可済み文書に固定した履歴セッションを使う。履歴アクセスの明示的なネイティブ確認は通常のFS信頼範囲を増やさない。
- [x] 本文・差分・履歴・画像・同時処理の上限、キャンセル／世代管理、破棄、サニタイズ、CSPを維持する。
- [x] 日本語・英語、キーボード操作、Escapeとフォーカス復帰、色だけに依存しない表示に対応する。

## 初版の境界

HEADから第一親をたどる現在パスの履歴。改名前の自動追跡、別ブランチ列挙、ZIP、linked worktree/submoduleの外部gitdir、外部object alternates、比較状態の永続化、比較の印刷／エクスポート、任意文書への履歴内リンク遷移は後続とする。

過去版のリンクは本文内アンカーだけ移動できる。外部画像は初版の比較ビューではブロックし、ローカル画像はリポジトリ内の該当版・通常ファイルblobだけを読む。
