# Hiranoa 0.3.2 QA

## Scope

Security-scan remediation for Markdown parsing, HTML sanitization, math rendering,
ZIP handling, TLS, certificate verification, and frontend build dependencies.
Includes selected Tauri and Rust maintenance updates. Broader library migrations
remain outside this release.

## Validation before version preparation

- Frontend formatting, ESLint, and svelte-check passed.
- All 419 frontend tests and 155 Rust library tests passed.
- Rust formatting and Clippy with warnings denied passed.
- Frontend coverage, performance-tool tests, frontend size limits, and production
  E2E-hook exclusion passed.
- Ten Windows WebView2 smoke scenarios passed, including Markdown and Mermaid
  math rendering. Production frontend rendering was also checked.
- Clean frontend installation verified the local deepmerge override. Regression
  tests cover prototype poisoning without changing the shared object prototype.
- Independent design/diff and security reviews completed before the individual
  remediation commits, with no unresolved P0/P1/P2 findings.
- The Windows release executable was built locally and accepted by the user.
- Fresh pre-publication audits on 2026-11-14 reported zero npm vulnerabilities
  and zero Cargo vulnerabilities, with five upstream Cargo advisory warnings.

## Remaining advisory warnings

Cargo reports glib 0.18.5 unsoundness (RUSTSEC-2024-0429), unmaintained
proc-macro-error (RUSTSEC-2024-0370), and unmaintained zbus_names, zvariant, and
zvariant_derive (RUSTSEC-2026-0371, RUSTSEC-2026-0370, RUSTSEC-2026-0372).
These are Linux dependency paths, absent from the effective Windows dependency
tree. Updating their upstream GTK/Tauri and zbus integrations is still required;
this release does not claim to eliminate those warnings or suppress advisories.

The deepmerge override remains a local patched fork because the official package
has not published a fixed release. The initial frontend size baseline was adjusted
after reproducing the build-tool update's size change; the existing five-percent
margin and other size baselines remain in place.

## Publication gates and limits

Version preparation, final release review, PR CI, tagged Windows/macOS/Linux
builds, and verification against SHA256SUMS.txt must complete before publishing
the draft. Final results are recorded in the release PR and GitHub Release.

Windows is the interactive runtime verification platform. Linux and macOS
packaging is checked by the release workflow; interactive runtime and installation
on those platforms are not covered. Windows binaries are unsigned and macOS
packages are not notarized. Full startup/memory benchmarks are not repeated for
this dependency-security release.
